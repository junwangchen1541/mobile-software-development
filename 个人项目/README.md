# 个人项目：我的暑假生活

「夏日足迹」是一个以“我的暑假生活”为主题的原生微信小程序社区。项目面向所有参与者：用户登录后发布自己的娱乐、学习、研究和生活记录，也可以浏览、点赞、评论和回复他人的内容。

## 页面结构

| 页面 | 内容 |
| --- | --- |
| 首页 | 社区主题、内容概览、精选记录和个人主页入口 |
| 足迹 | 分类筛选与日期时间轴，浏览社区中的暑假经历，并发布自己的足迹 |
| 详情 | 查看完整经历，进行点赞、评论、回复和分享；本人记录可编辑或删除 |
| 总结 | 根据当前本地记录统计不同分类的数量，展示阶段性收获 |
| 我的主页 | 本地演示登录、个人发布列表、发布入口和退出登录 |
| 发布足迹 | 新增或编辑日期、分类、文字、感受和图片 |

## 主要功能

- 按娱乐、学习、研究和生活分类筛选记录。
- 点击时间轴卡片进入详情页。
- 使用本地存储保存登录身份、个人发布、点赞、评论和回复，便于离线演示完整流程。
- 根据统一数据源自动生成首页内容、足迹列表和分类统计。
- 本人发布支持新增、编辑、删除，其他记录仅可浏览和互动。
- 使用微信原生分享能力分享单条暑假记忆。
- 使用响应式 `rpx` 布局适配移动端屏幕。

## 数据维护

课程示例记录存放在 `data/memories.js`；用户发布记录由 `data/store.js` 写入微信本地存储。每条记录包含日期、分类、标题、简介、完整经历、学习收获和感受体会，后续接入云数据库时可以沿用相同的数据结构。

```javascript
{
  id: 1,
  date: '07.10',
  category: '娱乐',
  title: '给假期留一点放松时间',
  summary: '在学习和研究之外，给自己留出恢复精力的时间。',
  content: '发生了什么……',
  learning: '学到了什么……',
  feeling: '感受与体会……'
}
```

## 导入运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择仓库中的 `个人项目/`。
4. 使用测试号或自己的 AppID，点击“编译”。

项目默认在公开配置中使用 `touristappid`，不包含真实 AppID 或其他私人信息。当前登录、发布和互动是单设备本地演示；要让不同手机上的用户真正共享内容，需要下一步接入微信登录、云数据库和云存储。
