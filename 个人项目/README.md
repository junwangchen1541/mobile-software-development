# 个人项目：我的暑假生活

「夏日足迹」是一个以“我的暑假生活”为主题的原生微信小程序。项目通过娱乐、学习、研究和生活四类记录，回答三个问题：暑假做了什么、学到了什么、留下了哪些感受。

## 页面结构

| 页面 | 内容 |
| --- | --- |
| 首页 | 暑假主题、统计概览、精选记录和总结入口 |
| 足迹 | 分类筛选与日期时间轴，浏览全部暑假经历 |
| 详情 | 查看完整经历、学习收获和感受，支持收藏和分享 |
| 总结 | 自动统计不同分类的记录数量，展示三点成长与最终感悟 |

## 主要功能

- 按娱乐、学习、研究和生活分类筛选记录。
- 点击时间轴卡片进入详情页。
- 使用本地存储收藏“难忘时刻”。
- 根据统一数据源自动生成首页内容和分类统计。
- 使用微信原生分享能力分享单条暑假记忆。
- 使用响应式 `rpx` 布局适配移动端屏幕。

## 数据维护

所有暑假记录集中存放在 `data/memories.js`。每条记录包含日期、分类、标题、简介、完整经历、学习收获和感受体会，后续可以直接替换为更精确的个人经历，无需修改页面结构。

```javascript
{
  id: 1,
  date: '07.10',
  category: '娱乐',
  title: '傍晚去海边走一走',
  summary: '沿着海岸慢慢散步，看日落把海面染成金色。',
  content: '发生了什么……',
  learning: '学到了什么……',
  feeling: '感受与体会……'
}
```

## 导入运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择仓库中的 `个人项目/`。
4. 使用测试号或自己的 AppID，点击“编译”。

项目默认在公开配置中使用 `touristappid`，不包含真实 AppID 或其他私人信息。
