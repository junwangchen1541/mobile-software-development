# 实验4：推箱子游戏

中国海洋大学《移动软件开发》实验四。项目使用微信小程序原生 Canvas 和绘图 API，实现一个包含四个关卡的简易推箱子游戏。

## 功能

- 关卡选择：首页以两列卡片展示 4 个关卡缩略图，点击后进入对应游戏。
- 地图绘制：使用 Canvas 绘制 8×8 地图、墙体、目标点、箱子和游戏角色。
- 推箱交互：通过上、下、左、右四个方向键移动角色，并按规则推动箱子。
- 结果判断：全部箱子进入目标点后弹出通关提示，并显示移动步数。
- 重新开始：随时将当前关卡恢复到初始状态。
