# 移动软件开发

中国海洋大学 2026 夏季学期《移动软件开发》课程实验仓库。

- 姓名：刘翼晨

## 实验目录

| 实验 | 内容 | 状态 |
| --- | --- | --- |
| [实验 1：第一个微信小程序](./实验1/README.md) | 手动创建 Hello World 微信小程序，实现按钮点击与页面数据更新 | 已完成 |
| [实验 2：名片小程序](./实验2/README.md) | 制作个人名片页面，实现简介展开、技能切换、收藏和分享 | 已完成 |

后续实验将继续以独立子目录的形式添加到本仓库。

## 运行实验 1

1. 克隆本仓库。
2. 使用微信开发者工具导入仓库根目录。
3. 选择自己的 AppID，完成后点击“编译”。

仓库根目录的 `project.config.json` 已将小程序源码目录设置为 `实验1/`。

实验 2 请直接将 `实验2/` 子目录导入微信开发者工具。
