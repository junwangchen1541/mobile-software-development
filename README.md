所有实验项目均以独立子目录的形式维护；实验报告和运行截图按课程要求单独提交。

## 运行实验 1

1. 克隆本仓库。
2. 使用微信开发者工具导入仓库根目录。
3. 选择自己的 AppID，完成后点击“编译”。

仓库根目录的 `project.config.json` 已将小程序源码目录设置为 `实验1/`。

实验 2 请直接将 `实验2/` 子目录导入微信开发者工具。

个人项目请直接将 `个人项目/` 子目录导入微信开发者工具。

## 实验 4

请将 `实验4/` 子目录导入微信开发者工具。项目使用本地关卡数据，不依赖云开发服务。

## 实验 5

请使用 DevEco Studio 打开 `实验5/` 子目录，配置 HarmonyOS SDK 和 Phone 模拟器后运行 `entry` 模块。
