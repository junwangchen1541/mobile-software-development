# 实验 6：基于云能力的图片分享社区

本项目根据课程实验文档实现“图片分享社区”微信小程序。用户可以浏览社区图片、查看个人主页、上传图片到云存储和云数据库，并在详情页下载、分享或全屏预览图片。

## 功能

- 首页按上传日期倒序展示图片卡片，显示头像、昵称、地区、图片和说明。
- 点击头像进入个人主页，按用户身份筛选上传历史。
- 上传页支持从相册或相机选择图片、填写说明、上传到云存储并写入 `photos` 集合。
- 详情页支持下载到本地相册、微信转发和全屏预览。
- 云能力不可用时自动切换到本地示例数据和本地缓存，便于离线编译验收。

## 云开发配置

1. 使用微信开发者工具导入 `实验6/`，在“云开发”中新建环境。
2. 创建数据库集合 `photos`，权限建议设置为“所有用户可读，仅创建者可写”。
3. 将 `cloudfunctions/getOpenid` 部署为云函数；需要真实用户 openid 时再在页面中调用该函数。
4. 在 `photos` 集合中使用 `photoUrl`、`avatarUrl`、`nickName`、`province`、`country`、`addDate`、`caption` 字段。

## 运行

导入 `实验6/` 后点击编译即可看到本地演示数据。配置云环境并部署云函数、数据库规则后，上传操作会自动使用 `wx.cloud.uploadFile` 和云数据库；没有云环境时不会阻塞页面体验。
