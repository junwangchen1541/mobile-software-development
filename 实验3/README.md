# 实验3：高校新闻网

中国海洋大学《移动软件开发》实验三，实现一个基于本地新闻数据的高校新闻小程序。新闻内容整理自中国海洋大学新闻网近期公开报道。

## 功能

- 首页：3 张图片自动轮播、新闻列表、点击新闻进入详情。
- 新闻详情：显示标题、图片、正文和日期；支持本地收藏与取消收藏。
- 个人中心：点击按钮获取微信头像和昵称；登录后显示收藏新闻列表，未登录时收藏列表为空。
- 底部 TabBar：在“首页”和“我的”两个页面之间切换。

项目使用从中国海洋大学新闻网公开页面整理的近期新闻和本地图片，不依赖云开发服务。
