# 实验 1：第一个微信小程序

本实验使用微信开发者工具手动创建一个 Hello World 小程序，不使用快速启动模板。小程序通过 WXML、WXSS 和 JavaScript 实现页面结构、视觉样式以及按钮交互。

## 实验目标

1. 熟悉微信开发者工具中新建、导入和编译小程序项目的基本流程。
2. 掌握不使用模板手动创建小程序所需文件的方法。
3. 理解 WXML、WXSS、JavaScript 和 JSON 配置文件的基本职责。
4. 使用数据绑定和事件处理实现点击按钮更新页面内容。

## 开发环境

- 开发工具：微信开发者工具 Stable
- 开发模式：原生微信小程序
- 页面技术：WXML、WXSS、JavaScript
- 运行环境：微信开发者工具模拟器

## 创建项目

在微信开发者工具中创建小程序项目，后端服务选择“不使用云服务”，并选择不使用模板或与之对应的空白项目。项目创建完成后，手动添加全局文件和首页文件。

## 项目结构

```text
实验1/
├── app.js
├── app.json
├── app.wxss
├── sitemap.json
└── pages/
    └── index/
        ├── index.js
        ├── index.json
        ├── index.wxml
        └── index.wxss
```

各类文件的作用如下：

| 文件类型 | 作用 |
| --- | --- |
| `app.json` | 注册小程序页面并配置导航栏、背景颜色等全局界面属性 |
| `app.js` | 声明小程序实例并保存全局数据 |
| `app.wxss` | 定义所有页面共用的基础样式 |
| `index.wxml` | 描述首页结构，绑定页面数据并根据状态切换按钮和成功提示 |
| `index.wxss` | 设置首页布局、颜色、字号和按钮交互样式 |
| `index.js` | 定义首页数据和 `sayHello` 点击事件 |
| `index.json` | 配置首页导航栏标题 |

## 核心实现

### 页面数据

首页在 `index.js` 中定义初始问候语和按钮状态：

```javascript
data: {
  message: '欢迎来到我的第一个微信小程序',
  greeted: false
}
```

WXML 使用双花括号将 `message` 显示到页面中：

```xml
<text class="message">{{message}}</text>
```

### 点击事件

按钮通过 `bindtap` 绑定 `sayHello` 方法：

```xml
<button wx:if="{{!greeted}}" bindtap="sayHello">
  Say Hello
</button>
```

用户点击按钮后，页面调用 `setData` 更新问候语和交互状态：

```javascript
sayHello() {
  this.setData({
    message: '很高兴见到你！',
    greeted: true
  })
}
```

当 `greeted` 变为 `true` 时，按钮通过条件渲染隐藏，页面显示“问候成功”。这一过程体现了小程序中“数据变化驱动界面更新”的基本机制。

## 运行方法

1. 克隆本仓库。
2. 打开微信开发者工具，选择“导入项目”。
3. 选择仓库根目录作为项目目录，并使用自己的 AppID。
4. 导入完成后点击“编译”，在模拟器中查看运行效果。
5. 点击 Say Hello 按钮，确认页面文字和状态发生变化。

仓库根目录的 `project.config.json` 已将 `miniprogramRoot` 设置为 `实验1/`，因此可以直接从仓库根目录导入。

## 问题与解决方法

### 新版工具增加了后端服务选项

创建项目时，新版微信开发者工具会要求选择后端服务。本实验不需要云函数、云数据库等能力，因此选择“不使用云服务”即可。

### 模拟器提示找不到 `app.json`

小程序源码位于仓库的 `实验1/` 子目录，而微信开发者工具默认在项目根目录查找 `app.json`。在根目录的 `project.config.json` 中增加以下配置后，开发者工具可以正确定位源码：

```json
{
  "miniprogramRoot": "实验1/"
}
```

## 实验总结

通过本实验，我完成了第一个原生微信小程序，并对不同文件的职责有了初步认识。WXML 用于组织页面结构，WXSS 用于控制页面样式，JavaScript 负责管理数据和响应用户操作，JSON 文件用于配置页面及小程序行为。按钮交互也说明了小程序通常通过 `setData` 更新数据，再由框架自动刷新界面。
